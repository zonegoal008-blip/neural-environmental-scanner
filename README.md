# Neural Environmental Scanner

A responsive, installable web app for iPhone, Android and desktop Chrome.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. The dashboard should load, but installation/offline features require HTTPS or localhost.
3. Internet access is required for live weather and air-quality data.

## Publish free with GitHub Pages
1. Create a GitHub repository named `neural-environmental-scanner`.
2. Upload every file in this folder to the repository root (not the containing folder).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Wait for deployment. Your site will be at `https://YOUR-USERNAME.github.io/neural-environmental-scanner/`.

## Install
- iPhone: open the published HTTPS website in Safari → Share → Add to Home Screen.
- Android: open it in Chrome → menu → Install app / Add to Home screen.
- Desktop Chrome: open the site → install icon in the address bar, or menu → Cast, save and share → Install page as app.

## Important
This is a Progressive Web App (PWA), not an App Store or Google Play Store listing. Store publication requires additional packaging and developer-account steps. The app uses Open-Meteo public APIs and displays modelled outdoor data; it has no physical sensors and is not an emergency or medical instrument.
